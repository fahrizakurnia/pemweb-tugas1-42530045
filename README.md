## Portofolio Pengembang Perangkat Lunak
landing page portofolio satu halaman yang diranvang menggunakan HTML dan CSS

### Deskripsi Fitur
    1. Header & Navigasi yang berfungsi untuk skip atau melompat ke bagian halaman yang diinginkan secara langsung.
    2. Tech Stack Skills yang menampilkan daftar keahlian yang dikuasai seperti Frontend, Backend & Database,dan Infrastruktur Cloud.
    3. Sertifikasi  Profesional yang menunjukan sertifikat kompetensi atau lisensi profesional yang dimiliki.
    4. Aksebilitas WCAG 2.1  yang memastikan situs web dapat diakses dengan mudah oleh semua orang dan memuat halaman dengan cepat
